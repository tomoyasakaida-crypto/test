# officee(オフィシー) 大阪オフィス物件 週次スクレイパー

[officee.jp](https://officee.jp) の賃貸オフィス一覧から、次の3条件に合致する物件を
抽出し、Excel リストを **週1回自動更新** するプログラムです。

| 条件 | 内容 |
|------|------|
| ① | 入居可能日が **現在より3ヶ月以上あと** |
| ② | 所在地が **大阪市**（区は問わない） |
| ③ | 面積が **30坪以上** |

> ※ ①②③の値は `config.py` で自由に変更できます（例: 2ヶ月以上、40坪以上 など）。

---

## 仕組み（なぜこの作りか）

- officee.jp は **Cloudflare のボット対策**で保護されており、通常の HTTP 取得
  (requests 等) は 403 で弾かれます。そのため **実ブラウザ (Playwright/Chromium)**
  でページを描画して取得します。
- robots.txt が `/search`・`/api/` を禁止しているため、**許可されている
  `/area/`（エリア×坪数の一覧ページ）だけ**を対象にします。
- 「大阪市」の区別ページは内部コード (`/area/OA1:OA2:OA3/`) で推測できないため、
  **大阪府全体の30坪以上ページを巡回し、住所に「大阪市」を含む物件だけ**残します。
- サイトに負荷をかけないよう、ページ遷移ごとに **5〜11秒の待機**を入れ、
  実行は **週1回**のみです。

> **注意:** スクレイピングの可否は officee.jp の利用規約をご確認のうえ、自己責任で
> ご利用ください。本ツールは自社のオフィス探し目的・低頻度・低負荷を前提としています。

## セットアップ（Windows・初回のみ）

1. **Python 3.10 以上**をインストール
   （<https://www.python.org/downloads/> → インストール時に **Add python.exe to PATH** にチェック）
2. このフォルダ内の **`setup_windows.bat` をダブルクリック**
   - 仮想環境作成 → ライブラリ導入 → Chromium 導入 → 自己テストまで自動で行います。

## 使い方

### 手動で1回実行
`run_weekly.bat` をダブルクリック。完了すると
`output\officee_osaka_offices.xlsx` が作成／更新されます。

### 週1回の自動実行（タスクスケジューラ登録）

1. スタートメニューで「**タスク スケジューラ**」を開く
2. 右側「**基本タスクの作成**」をクリック
3. 名前: `officee週次スクレイピング` → 次へ
4. トリガー: **毎週** → 実行したい曜日・時刻（例: 毎週月曜 9:00）→ 次へ
5. 操作: **プログラムの開始** → 次へ
6. プログラム/スクリプト欄に、この **`run_weekly.bat` のフルパス**を指定
   （「参照」から選ぶのが確実。例: `C:\Users\あなた\officee_scraper\run_weekly.bat`）
7. 完了

> 無人実行にする場合は、`run_weekly.bat` の最終行 `pause` を削除してください。

## ★ 初回の重要ステップ：セレクタの現地確認

officee の HTML 構造（CSS クラス名）は当方で直接確認できないため、
**初回だけ実サイトに合わせた確認**を推奨します（数分で終わります）。

```bat
.venv\Scripts\python scraper.py --inspect "https://officee.jp/area/p_osaka/30_50/"
```

- `debug\page.html`（描画後HTML）と `debug\page.png`（スクショ）が保存されます。
- コンソールに「推定カード数」とカード例が表示されます。
  - **カードが正しく取れていれば、そのまま運用可能**です（本ツールは坪数・賃料・
    住所・入居日をテキストから正規表現で拾うため、多くの場合セレクタ未設定でも動きます）。
  - うまく取れない場合は `debug\page.html` を見て `config.py` の
    `SELECTORS["card"]` 等を実際のクラス名に合わせてください。
  - **`debug\page.html` を共有いただければ、こちらでセレクタを確定します。**

## 出力される Excel の中身

`output\officee_osaka_offices.xlsx`（3シート構成）

- **物件一覧** … 3条件すべて合致した物件。主キーで毎週 upsert し、
  `初回取得日`／`最終確認日`／`ステータス`（新規・継続・掲載終了）で変化を追跡。
  掲載終了しても行は残す（履歴保持）。新規行は緑、掲載終了行はグレー表示。
- **入居日不明** … 大阪市・30坪以上だが入居可能日が「応相談」等で判定できない物件
  （見落とし防止のレビュー用）。
- **実行ログ** … 毎回の取得日・件数の記録。

主な列: 建物名 / 住所 / 坪数 / 賃料 / 入居可能日(記載) / 入居可能日(解析) /
条件①②③ の ○×△ / 詳細URL / 初回取得日 / 最終確認日 / ステータス

## 設定変更（`config.py`）

| 項目 | 既定 | 説明 |
|------|------|------|
| `MOVEIN_MIN_MONTHS` | 3 | 入居可能日の下限（ヶ月） |
| `CITY_KEYWORD` | 大阪市 | 住所フィルタ |
| `MIN_TSUBO` | 30.0 | 面積下限（坪） |
| `SIZE_RANGE_PATHS` | 30〜200坪超 | 巡回する坪数レンジURL |
| `INCLUDE_UNKNOWN_MOVEIN` | False | 入居日不明を一覧に含めるか |
| `HEADLESS` | True | ブラウザ画面を表示するか（Falseで安定する場合あり） |
| `OUTPUT_XLSX` | output/... | 出力先 |

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| `--inspect` で title が「Just a moment」のまま | `config.py` で `HEADLESS=False`、`CLOUDFLARE_WAIT_SEC` を増やす |
| 推定カード数が 0 | `debug\page.html` を確認し `SELECTORS["card"]` を設定 |
| 入居日が全部「不明」 | 詳細ページ側の表記の可能性。`--inspect` で詳細ページも確認 |
| 途中で止まる | 待機時間 `REQUEST_*_DELAY_SEC` を長めに |
